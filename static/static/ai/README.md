# 🏨 Smart Hotel Management System

A Smart Hotel application for food ordering,
table management and AI-based CCTV monitoring.

## Features

- Customer tablet interface
- Food menu
- Food images
- Shopping cart
- Table selection
- Online order creation
- Admin dashboard
- Table availability
- Order status management
- CCTV person detection
- YOLO AI module
- SQLite database

## Technologies

- Python
- FastAPI
- SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript
- OpenCV
- YOLO
